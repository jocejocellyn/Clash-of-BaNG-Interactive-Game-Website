# Clash-of-BaNG-Interactive-Game-Website
A fantasy-themed community website concept built as a Human-Computer Interaction project, combining UI/UX design with front-end web development. The website was designed in **Figma** and implemented using **HTML, CSS, and JavaScript**, with a focus on responsive layouts, interactive components, and a consistent dark fantasy visual identity.

## Project Overview
Clash of BaNG is a multi-page website concept inspired by a fantasy strategy game community. The website consists of five main pages:
* Home
* Gallery
* Troop
* About
* Register

The project was designed to provide users with an immersive way to explore game-related content, including troops, heroes, artwork, battle maps, and community information.

## Design Process
The interface was first designed in **Figma** before being implemented as a functional website.The design focused on:
* Dark fantasy visual identity
* Consistent typography and visual elements
* Clear navigation between pages
* Interactive content presentation
* Responsive layouts for different screen sizes

## Main Features
### Home Page
The Home page acts as the main entry point and includes:
* Game update slider
* Featured troop section
* Community introduction
* Responsive navigation

### Gallery Page
The Gallery page organizes visual content into several categories:
* Heroes
* Troops
* Artwork
* Battle maps

Interactive sliders, hover effects, and responsive layouts allow users to browse the content.

### Troop Page
The Troop page presents heroes and troop information through interactive cards. Hover interactions reveal additional battle statistics such as:
* Hitpoints
* Damage per second
* Range
* Speed
* Damage type

### About Page
The About page introduces the fictional community through:
* Community history
* Timeline of important events
* Founder profiles
* A Join the Vanguard section with troop exploration and registration options

### Register Page
The Register page provides a responsive registration form with fields including:
* Warrior name
* Email
* Age
* Gender
* Favorite hero or battalion
* Reason for joining

JavaScript validation was implemented to check whether submitted information is complete and properly formatted.

## Responsive Design
The website was designed for both desktop and mobile screen sizes. Interactive elements such as hover effects, sliders, transitions, and buttons were also adjusted to maintain a consistent experience across screen sizes.
